# Course Compass

Course Compass is a web-based college course recommendation tool designed to help students explore degree programs based on their interests, strengths, and preferences.

The application uses a 20-question assessment to evaluate different traits such as logic, creativity, communication, leadership, attention to detail, hands-on skills, people skills, and science. Based on the results, the system compares the user's profile with 39 college programs and provides the top 3 recommended courses with match percentages.

## Features

* Interactive compass-inspired user interface
* 20-question career and course assessment
* 39 college programs
* Trait-based scoring system
* Top 3 course recommendations
* Match percentage for each recommendation
* Strongest trait identification
* 4-year course overview
* Possible career paths for each program
* Option to retake the assessment

## Built With

* HTML5
* CSS3
* JavaScript
* SVG
* Google Fonts

## Purpose

Course Compass was created as a web development project focused on interactive user interfaces, JavaScript-based scoring, and personalized course recommendations. It is intended for course exploration and self-discovery and should not be considered a replacement for professional career guidance.
